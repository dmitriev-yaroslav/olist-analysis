# Аналитика маркетплейса Olist

Анализ данных бразильского маркетплейса Olist. Цель - выявить проблемные зоны в логистике, оценить качество товаров и определить регионы-лидеры по выручке.

## О репозитории

В репозитории представлен сквозной аналитический проект: от проектирования базы данных и написания SQL-запросов до визуализации результатов в Tableau. Проект воспроизводим в среде PostgreSQL и DBeaver.

## Анализ логистики и качества товаров

### Задача

Маркетплейс Olist столкнулся с проблемой: клиенты ставят низкие оценки. Бизнесу нужно понять, что именно вызывает недовольство - медленная доставка, плохое качество конкретных категорий товаров или проблемы в определенных регионах. Результаты предназначены для отдела логистики и категорийных менеджеров.

### Исходные данные

Датасет Brazilian E-Commerce Public Dataset by Olist содержит информацию о 99 441 заказе, разбитую на 9 нормализованных таблиц (клиенты, заказы, товары, платежи, отзывы, геолокация и т.д.). Данные охватывают период с 2016 по 2018 год. Файлы лежат в папке `data/raw/`.

### Методология

1. **Подготовка данных (Data Mart):** созданы SQL-представления `fact_orders` и `fact_reviews`, объединяющие данные о заказах, товарах и отзывах. Это позволило исключить дублирование и упростить анализ.
2. **SQL-анализ:** написаны запросы с использованием `JOIN`, `GROUP BY`, `HAVING`, `CASE` и оконных функций для расчета средних рейтингов, поиска аномалий и анализа временных задержек.
3. **Визуализация:** результаты выгружены в CSV и загружены в Tableau для построения интерактивного дашборда (карта выручки, график влияния опозданий, топ проблемных категорий).

### Результаты

1. **Опоздания критически влияют на рейтинг.** Если заказ доставлен вовремя, средний рейтинг составляет **4.21**. Если опоздание превышает 4 дня, рейтинг падает до **1.86**.
2. **Проблемы с качеством в категории мебели.** Категория `office_furniture` имеет самый низкий рейтинг (**3.62**) даже при условии своевременной доставки. Это указывает на проблемы с качеством сборки, упаковкой или соответствием описанию.
3. **Географические аномалии.** Штат **Сан-Паулу (SP)** - абсолютный лидер по выручке (5.8 млн). Однако в штатах **PA** и **RJ** рейтинг мебели падает до критических 2.88 и 3.41, что требует проверки локальных продавцов.

### Стек

PostgreSQL, SQL (CTE, оконные функции), DBeaver, Python (экспорт данных), Tableau.

## Структура проекта

* `sql/` - SQL-скрипты (создание представлений и аналитические запросы).
* `data/` - исходные данные (CSV).
* `README.md` - описание проекта.

## Запуск

1. Разверните базу данных PostgreSQL (например, через DBeaver).
2. Выполните скрипты из папки `sql/` по порядку (сначала `01_setup_views.sql`, затем аналитические).
3. Выгрузите результаты запросов в CSV.
4. Откройте файлы в Tableau для просмотра дашборда.
